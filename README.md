# Солнечная система · 3D

Интерактивная 3D-демонстрация Солнечной системы на [Three.js](https://threejs.org/): Солнце и восемь планет на орбитах, реальная (сжатая для наглядности) схема масштабов, управление воспроизведением и скоростью, карточка с данными о планете по клику.

**Живая демо-страница:** https://garist0308.github.io/solar-system-3d/

## Возможности

- Реальные 2K-текстуры NASA/Solar System Scope для Солнца и всех планет
- Земля: облака, ночные огни городов, нормали рельефа и атмосферная дымка
- Венера: плотная облачная атмосфера, скрывающая поверхность, как в реальности
- Сатурн: кольца по настоящей альфа-карте прозрачности
- Луна на собственной орбите вокруг Земли
- Пояс астероидов между Марсом и Юпитером (900 инстансированных камней)
- Млечный путь на фоне + звёздное поле
- Избирательный bloom (свечение) только для Солнца — планеты остаются чёткими
- Орбитальное движение всех 8 планет с собственными скоростями и наклоном оси
- Клик по планете/Солнцу/Луне — карточка: название, диаметр, расстояние, орбитальный период, длина суток, число спутников, интересный факт
- Play/Pause и плавный слайдер скорости симуляции
- Переключение подписей, сброс камеры, вращение/zoom мышью или тачем
- Адаптивная вёрстка для мобильных устройств

## Технологии

Чистый HTML/CSS/JS, без сборки — Three.js подключается через `importmap` с CDN (unpkg). Откройте `index.html` через любой локальный сервер (не напрямую через `file://`, так как используются ES-модули).

```bash
npx serve .
# или
python3 -m http.server 8080
```

## Деплой

Статический сайт, готов к GitHub Pages «из коробки» — просто указать ветку `main` и корень `/` в настройках Pages.
